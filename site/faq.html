FAQ

Does it run on other headsets?
No. FramePlayerX is built only for the Steam Frame, so it can use the Frame's decoder, controllers and runtime directly instead of carrying everything a cross-platform player needs.
Which videos play best?
HEVC (H.265), H.264, and AV1 (on SteamOS 0.5.10 and later): the Frame's hardware decoder plays them smoothly up to 8K. The Frame has no hardware decoder for 4:2:2 video (or AV1 on earlier SteamOS versions), so those play on the CPU, which can fall behind at VR sizes; a pill on the control bar shows when a video plays this way. Converted once to HEVC on a PC, they play as smoothly as the rest; the user guide has the commands.
Does it work with my media server or NAS?
Yes, if it offers one of these: Jellyfin (sign in with Quick Connect or a password), Emby (a password), Plex (sign in with a linking code or an access token), a DeoVR feed or HereSphere API, SMB, NFS, SFTP, WebDAV or DLNA. Add it under Sources › Add source.
Will it be released on Steam?
Not for now. I develop FramePlayerX for myself in my free time, and I don't see the point in paying Steam's $100 fee to publish it. If donations through GitHub Sponsors ever reach that amount, I'll spend them on releasing it on Steam. I don't expect any, though: it's an app built with the help of AI to solve an immediate need of my own. Meanwhile, the installers add it to your Steam library like a game.
Why a fork instead of contributing to FramePlayer?
FramePlayer reached Jellyfin, where most of the films I wanted to watch are, only through DLNA, and I wanted to use it directly. It also didn't support half side-by-side videos. I also had a different idea for browsing sources than its library screen, and while FramePlayer focuses on adult videos, I wanted a player for every kind of media. Together that made a different app rather than a few changes to the original.
Do you plan to add new features?
If I come across a new idea or receive a suggestion that fits a VR video player for the Frame, I will consider adding it, but there are no promises: this project exists to solve my own needs first.
Something isn't working. Where can I get help?
Start with Troubleshooting in the user guide. If that doesn't cover it, open an issue on GitHub saying what you did and what happened.
How can I get in touch?
Reach out on the FramePlayerX Discord server, or by email at the address this page shows with JavaScript on.
Can I help translate?
Yes. Every language but English started as a machine draft, so some wording is likely to be wrong or awkward. Corrections are welcome on Codeberg Translate: sign in with a Codeberg account, pick a language and edit its messages, no Git needed.
